# 선택한 뉴스 · UI 에셋

864 × 1536 px 시안에서 분리한 투명 PNG 27개다. 원본과 같은 배치로 조합하려면 `layout.json`에 기록한 순서대로 겹친다. 좌표는 원본 화면 왼쪽 위를 기준으로 하며 각 PNG의 투명 여백까지 포함한다.

| 폴더 | 구성 |
| --- | --- |
| `chrome/` | 기사 테두리와 바탕, 가로 구분선, 진행 막대의 트랙과 채움, 안내 패널, 버튼과 배지 |
| `icons/` | 뒤로 가기, 코인과 추가 버튼, 주사위, 안내판, 과녁, 책, 보상 왕관과 좌우 월계수 |
| `art/` | BET 헤더, AI·저작권 예시 기사 삽화, 좌우 칩, 금빛 반짝임, 하단 빛 고리 |

기사 카드는 `article-surface.png` 위에 `article-frame.png`를 겹치고 안쪽에 기사 삽화와 내용을 배치한다. 제목·매체·날짜·본문·버튼 문구·잔액·보상 수치는 게임에서 표시한다. 삽화 안의 ‘AI’와 저작권 기호, 헤더의 ‘BET’는 그림에 포함되어 있다.

읽기 진행률은 `progress-track.png` 위에 `progress-fill.png`를 왼쪽에 맞춰 올린다. 배치표의 채움 너비는 원본 40% 예시다. 비율이 달라질 때는 채움의 가운데 부분만 늘리고 양 끝의 둥근 모서리와 광택은 유지한다.

단일 JPEG에서 가려졌던 버튼 안쪽과 카드 바탕은 주위 색을 이어 복원했다. `stage-ring.png`는 원본에서 버튼에 가려진 하단 빛 고리를 이미지 생성으로 복원한 장식이며 배치표에는 권장 좌표를 적었다.
